# Onboarding: Python for Data Science

Welcome to the course! This repository contains all the materials, exercises, and projects you need to master Python for Data Science over the next 16 weeks.

## Getting Started
1. **Clone the Repository**:
   ```bash
   git clone <your-repository-url>
   cd python-data-science-curriculum
   ```

2. **Environment Setup**:
   It is highly recommended to use a virtual environment.
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

## Weekly Workflow
Each week follows a flipped-classroom model:
1. **Review**: Read the `course_website/explanations/Week_X_Explanation.md` file.
2. **Practice**: Work through the `homework/notebooks/Week_X_*.ipynb` file.
3. **Apply**: Complete the "Practice" section linked in the explanation file (Exercism or Kaggle).
4. **Submit**: Push your work to your dedicated weekly folder in the repository (`homework/weekX/`).

If you have questions or need code review, please open a **Pull Request** in your repository with your weekly work, and I will review it.
