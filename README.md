# Python for Data Science Curriculum

Welcome to the Applied Data Science residency. This curriculum takes you from Python mastery to professional-grade data science development over 16 weeks.

## Repository Structure
- `course_website/`: Quarto project for the course documentation.
- `homework/notebooks/`: Weekly Jupyter notebooks for active learning.
- `homework/weekX/`: Folders for your weekly submissions.
- `capstone_template/`: Starter template for your final project.

## How to use this repository
1. Read the explanation in `course_website/explanations/`.
2. Work through the corresponding notebook in `homework/notebooks/`.
3. Complete the practice challenges.
4. Submit your work via Pull Request.

## Requirements
See `requirements.txt` for environment setup.
