# Week 10: Supervised Learning - Algorithms

## Overview
This week provides a deep dive into fundamental supervised learning algorithms, covering the transition from simple linear models to powerful, non-linear tree-based approaches.

## Key Concepts
### 1. Linear & Logistic Regression
- **Predictive Foundation**: Linear regression models continuous targets, while logistic regression models binary (or multi-class) probabilities. They are the essential baseline for any supervised learning project.

### 2. Tree-Based Models
- **Handling Non-Linearity**: Decision trees and ensemble methods like Random Forests handle non-linear data relationships efficiently, making them robust choices for complex datasets without requiring heavy feature engineering.
- **Feature Importance**: These models provide intuitive mechanisms to understand which features are driving predictions, adding interpretability to the modeling process.
