# Week 2: Object-Oriented Python for Data Science

## Overview
Moving from functional scripts to structured, object-oriented code is essential for developing maintainable, reusable, and scalable data science pipelines.

## Key Concepts
### 1. Classes and Special Methods
- **Encapsulation**: Classes group data and behavior, ensuring a clean interface for interaction.
- **Dunder Methods**: Special methods (e.g., `__init__`, `__repr__`, `__getitem__`) allow objects to integrate seamlessly with Python's built-in operators and functions, enabling a more natural programming experience.

### 2. Dataclasses
- **Boilerplate Reduction**: `dataclasses` automatically generate useful methods like `__init__`, `__repr__`, and `__eq__`, allowing you to define structured, data-holding classes with minimal code.
- **Type Hinting**: They pair naturally with type hints, improving code clarity and enabling better IDE support, which is critical for complex projects.
