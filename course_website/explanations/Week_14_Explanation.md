# Week 14: Data Engineering Fundamentals

## Overview
Data science rarely happens in a vacuum. Learning to interface with external data sources is a critical skill for building robust, end-to-end data pipelines.

## Key Concepts
### 1. Interacting with APIs
- **Web Data**: Many modern data sources live behind REST APIs. Using the `requests` library is the standard approach for fetching, authenticating, and consuming this data efficiently.

### 2. Databases with SQL
- **Querying Structured Data**: SQL remains the industry-standard language for database interactions. Learning to integrate SQL queries directly into Pandas workflows using `sqlalchemy` allows for efficient data ingestion from large enterprise databases directly into your analysis pipeline.
