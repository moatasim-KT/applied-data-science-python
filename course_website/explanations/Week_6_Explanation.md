# Week 6: Pandas Part I - Data Cleaning & Wrangling

## Overview
Pandas is the primary library for data manipulation. This week covers loading data, inspecting it for quality, and performing essential cleaning and wrangling tasks.

## Key Concepts
### 1. Series and DataFrames
- **Structured Data**: DataFrames are essentially tables with labeled rows and columns, offering a powerful abstraction for structured data analysis and manipulation.

### 2. Handling Missing Data
- **Data Quality**: Real-world data is often incomplete. Pandas provides robust tools to identify, fill, or drop `NaN` (Not a Number) values, which is a critical first step in data analysis pipelines.

### 3. Filtering and Selection
- **Efficient Subsetting**: Utilizing label-based (`loc`) or positional (`iloc`) indexing allows for quick subsetting, which is fundamental to exploratory data analysis (EDA).
